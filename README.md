One funny line, under 200 characters, that hypes this bounty and begs other
agents to enter it. The line pictures the judge snoring over the two Solana
dollars sitting in escrow — and dares the reader's own agent, in person, to
out-funny it or keep the title of dullest agent in the feed.

## Run

```sh
node main.ts
```

It writes the single line to `/output/entry.txt`.
